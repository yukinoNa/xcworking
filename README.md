# 宣传部工作台

部门工作排期 + 双通道约稿/合作。一个人维护，零成本。

---

## 一、启动

拿到代码：

```powershell
git clone <仓库地址>
cd publicity-hub
npm install
```

> 什么都不用配。首次启动会自动生成 `data/` 目录和几条示例排期，打开就能看到完整界面。
> 仓库里**不含**任何真实的订单、客户联系方式或上传素材——那些都在 `.gitignore` 里。

以后每次：

```powershell
npm start
```

浏览器打开 **http://localhost:5173**
启动时控制台会打印 **局域网地址**（发给别人用的）和 **内部看板口令**。

> 口令只保存在当前标签页里，**关掉网页后重新打开要再输一次**，不会留在电脑上。想换成固定的就设环境变量 `ADMIN_PASSWORD` 再启动。

---

## 二、两个入口

对外只有 **一个链接**：`你的地址/order.html`。打开后是选择题：

| 入口 | 给谁 | 表单差异 |
|---|---|---|
| **部门 / 学生组织** | 各部门、组织的宣传活动需求 | 部门名、联系方式、需求描述 |
| **委托 / 商业合作** | 摄影、剪辑、设计、外包等项目 | 多要客户名称、服务地点、预算、票据需求 |

两条路提交的单子会自动带上渠道标记，在内部看板里用 **全部 / 部门组织 / 委托合作 / 加急** 一键筛。

> 页面上不出现"免费 / 收费"这类字眼，两类入口靠身份区分。

## 三、日常怎么用

### 1. 排期：不用再编辑 Excel 了

排期有三个来源，前两个**全自动**：

| 来源 | 怎么进 |
|---|---|
| 看板里**接单**的委托 | 点「→ 制作中」自动生成排期项；退回待接单或拒接，自动移除 |
| 已有的旧数据 | 首次启动时自动从 `schedule.xlsx` 导入，之后不再读它 |
| **不是委托来的活** | 到「排期管理」页填表单（见下） |

**什么时候还要手动录？** 只有那种没人"约"、学校直接通知你的活——比如校运会叫你去拍。这种情况去 `/admin.html`，点顶部「排期管理」标签：

填项目名、类型、**开始日期**、**结束日期**、负责人、需求方，点「添加到排期」。

- **结束日期留空 = 只有一天**
- 填了结束日期，这个任务会在月历上**连续覆盖这几天**
- 状态只能是 `待接单` / `制作中` / `已交付`
- 列表里点「修改」可以改任意字段，「删除」移除

> 旧的 `data/schedule.xlsx` 只在第一次启动时被读一次，导进 `data/schedule.json`。之后你改 Excel 不会有任何效果——留着当历史备份就行。

### 2. 三种视图

排期页顶部可以切换：

| 视图 | 用途 |
|---|---|
| **周**（默认） | 一行一天，横向排。**跨天的活是一条连续横条**，从开始日一直画到结束日，右边标注天数 |
| **月历** | 整月概览。只有当天有活的格子才会出现条目，不再有一堆空行 |
| **列表** | 按开始日期分组的文字清单，适合手机上翻 |

周视图里左侧是类型（推文/设计/绘画/摄影/视频/AI 绘图/其他），每种类型一行，同一类型下时间不冲突的活会自动并排错开。

**鼠标悬停在任意条目上**（三种视图都支持）会弹出详情卡：完整时间范围、负责人、需求方、备注、来源。

委托来的条目边框是**虚线**；已交付的会变淡并划掉。**待接单的委托不会显示在排期页**——还没接的活不对外公示。

### 3. 改制作周期

打开 **`data/cycles.json`**，一个类型一行：

```json
{ "type": "推文", "label": "公众号推文", "days": 7, "text": "约 1 周" }
```

- `days` 填天数，用于**自动加急判定**
- `days` 填 `null` = 暂时按项目商谈，不参与加急判定
- `text` 是网页上显示的文字
- 改完保存，刷新网页即生效，不用重启

当前配置：**推文约 1 周 · 海报设计 1–2 周 · 绘画插画 1–2 周 · 摄影跟拍次日返图 · 剪辑 1 周内 · AI 绘图按项目商谈**。

> AI 绘图还没定工期，所以它现在不参与加急判定。你告诉我几天，我把 `cycles.json` 里那行的 `null` 换掉即可。

改了这个文件以后，约稿表单会自动按类型提示工期；客户填的期望日期如果短于工期，**自动标记加急**，看板上会跳红标签。判定在前端和后端用的是同一套算法，两边不会打架。

### 4. 处理约稿

打开 `/admin.html` 输口令，四列看板：

```
待接单  →  制作中  →  已交付

  ↓
已拒绝
```

- **接单**：点「→ 制作中」
- **拒接**：点「拒接」，会问你一句原因（可以留空）。单子挪进「已拒绝」列并**保留记录**，方便你回复对方时想起来为什么没接
- 放错了可以点「退回待接单」重新处理
- 商业单会显示客户、预算、地点、票据；加急单左侧有红条 + 红色「加急」标

### 5. 排期页的数据从哪来

排期页只读 `data/schedule.json`，里面有三种来源：

| 来源 | 怎么进 |
|---|---|
| 看板里**接单**的委托 | 自动生成一条，退回待接单或拒接时自动移除 |
| 内部看板「排期管理」手动录入 | 你自己排的计划 |
| 首次启动的示例数据 | 只在全新环境生成一次，有数据后不再出现 |

`待接单` 和 `已拒绝` 的单**不会**出现在排期页——还没接的活、别人拒掉的活，外部都看不到。

## 四、数据在哪、怎么备份

| 位置 | 是什么 |
|---|---|
| `data/schedule.json` | 排期表（看板里改） |
| `data/cycles.json` | 制作周期配置，你手动编辑 |
| `data/orders.json` | 所有需求单（含渠道、加急标记） |
| `uploads/` | 客户上传的素材 |
| `data/admin-key.txt` | 看板口令 |

**备份 = 把 `data/` 和 `uploads/` 两个文件夹复制走。**

**换电脑** = 整个文件夹拷过去 → `npm install` → `npm start`。

## 五、以后想真正上线

1. **需要一台常开的机器或云主机**。素材存在磁盘上，Vercel 这类无状态免费平台**不合适**（重启丢文件）。
2. **域名 + HTTPS**：不备案就用境外/香港节点，或者直接用 `IP:端口`。
3. **口令必须换成复杂的**。当前是 `123456`，局域网里自用没问题，但**上线前一定要改**——公网上这种口令几秒就被试出来，订单里的姓名电话会全部泄露。改法：编辑 `data/admin-key.txt` 写入新口令后重启，或者启动时设环境变量 `ADMIN_PASSWORD`。
4. **`uploads/` 要单独备份**，这是最容易丢的东西。
5. 商业单涉及收款，收款流程网页不做，线下走。

## 七、视觉规范（改样式前请读）

暖色底 + 毛玻璃 + 克制动效。所有可调的值都在 `styles.css` 顶部的 `:root` 里，改那里就行，别去改具体规则。

**配色**

| 变量 | 用途 |
|---|---|
| `--accent` `#bf4a2e` | 主色，按钮、链接、今天、加急 |
| `--ink` / `--muted` | 正文 / 次要文字 |
| `--glass` | 卡片底色（半透明白，让背景透上来） |
| `--blur` `22px` | 毛玻璃模糊半径（手机端自动降到 14px） |

**背景不能是纯色。** 毛玻璃要透出东西才成立，所以 `body::before` 铺了一层固定的暖色光晕。如果你把背景改成一整片纯色，所有卡片会立刻变成没质感的灰白块。

**动效**都在这几个变量下：`--fast` `.16s` / `--mid` `.28s` / `--ease` 一条贝塞尔。想调快慢改这三个值即可。

已经做了的微交互：卡片 hover 上浮、按钮按下回弹、主色按钮的光泽、输入框聚焦光圈、类型标签 hover 位移、看板卡片 hover 抬升、加急标签呼吸、口令窗弹出、列表项逐条淡入。系统开了「减少动态效果」时全部自动关闭。

**改样式时注意**

- 毛玻璃元素不宜过多，每个 `backdrop-filter` 都是一次实时合成。列表里的每一项不要加，只给容器加。
- 手机端遮挡和性能都敏感，`--blur` 已经在 900px 以下降到 14px，别再调高。
- iOS 上输入框字体小于 16px 会触发页面自动放大，这一条已经在媒体查询里锁住了，别改。

## 八、已知限制

- **没有分页**：几百条没问题，上万条会慢。
- **没有登录系统**：一个口令挡着，挡的是误点进来的人，不是专业攻击。
- **没做并发写锁**：同一秒两个人提交理论上可能抢同一编号，部门量级遇不到。
- **手机端没精调**：月历在小屏很窄，手机上建议用"列表"视图。
- **商业单不做在线收款**：报价、合同、打款都在线下完成，网页只负责收集意向和排期。
